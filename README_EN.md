<h2 align="center">✨ Using in AI Tools</h2>

AntV [Sive](https://sive.antv.antgroup.com/) provides `API Key` for free use in AI tools. Simply log in and navigate to **Profile Center - Settings - API Key** to create one for free. Then copy the prompt below and send it to your local AI to generate the "Sive Data Analysis Skill".

```
This document provides the installation instructions for the AI Data Analysis Skill. Follow this document to generate the "Sive Data Analysis Skill" in your local AI environment, ensuring no information is lost.

1. Ask the user to provide their Sive Data Analysis <API Key>, which can be created for free in the [Sive](https://sive.antv.antgroup.com/) product under "Profile - Settings - API Key".
2. Load the OpenAPI interface documentation provided by Sive at https://sive.antv.antgroup.com/api/open/v1/load-sive-skills.
3. Based on the loaded information, generate the "Sive Data Analysis Skill" in your local AI environment, ensuring the Skill name and description conform to the specification.

Once installed, you can use the "Sive Data Analysis Skill" for data import, query analysis, and visualization. For example:

> Load the local CSV file 'sales.csv', analyze the 'sales trend over the last 10 days', and render the result as a line chart.
```
