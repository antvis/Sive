# Sive

**用自然语言探索数据，把分析过程和结果留在一个工作台里。**

Sive 是基于 [AntV AVA](https://ava.antv.vision/) 的开源桌面数据分析工具。描述你想了解的问题，即可查看查询过程、计算数据和可交互图表，并将有价值的分析保存、刷新或导出。

适合业务数据探索、日常指标分析，以及需要核对 SQL 和计算依据的分析场景。

[English](README.en.md)

## 核心能力

- **统一管理数据**：导入 CSV、Excel（XLSX）、JSON、Parquet，或连接 MySQL。支持连接测试、编辑、重新验证，以及数据库多表浏览。
- **先看数据，再开始分析**：查看字段、主键、索引和数据预览，可补充业务口径和指标定义，让分析贴近实际业务。
- **看得见的分析过程**：展示真实的数据准备、查询生成、SQL 执行、纠错、总结和绘图进度。可以查看耗时、执行 SQL、结果数据，或停止当前任务。
- **保存与复用分析**：手动保存有价值的结果，以卡片展示可交互图表、数据和 SQL。支持刷新数据，并通过“查看分析”返回原始对话。

## 开发指南

准备 Node.js >=22.13.0 和 [pnpm](https://pnpm.io/installation) 10.30.3，在项目目录执行：

```sh
pnpm install
pnpm run electron:install
pnpm dev
```

后续启动只需执行 `pnpm dev`。开发模式支持界面热更新；主进程或后端变化会重启应用，preload 变化会刷新窗口。

| 命令           | 用途                                    |
| -------------- | --------------------------------------- |
| `pnpm check`   | 类型检查                                |
| `pnpm build`   | 构建应用                                |
| `pnpm package` | 生成当前平台的应用包，输出至 `release/` |

界面代码位于 `src/`，业务逻辑位于 `backend/`，桌面入口位于 `electron/`，跨端公共代码位于 `shared/`。开发和构建配置统一在 `electron.vite.config.ts`。
