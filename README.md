# Sive

**用自然语言探索数据，把分析过程和结果留在一个工作台里。**

Sive 是基于 [AntV AVA](https://ava.antv.vision/) 的开源桌面数据分析工具。描述你想了解的问题，即可查看查询过程、计算数据和可交互图表，并将有价值的分析保存、刷新或导出。

适合业务数据探索、日常指标分析，以及需要核对 SQL 和计算依据的分析场景。

[English](README.en.md)

## 核心能力

- **统一管理数据**：导入 CSV、Excel（XLSX）、JSON、Parquet，或连接 MySQL。支持连接测试、编辑、重新验证，以及数据库多表浏览。
- **围绕数据源分析**：每个数据源一个标签，左侧切换会话历史；全局“新建会话”沿用当前数据源，未选中时先选择数据；数据面板默认展开，可查看预览、字段结构和数据语义，补充业务规则与指标定义；拖动中间分隔条调整宽度，展开与收起使用面板右上角的同一按钮。
- **看得见的分析过程**：展示真实的数据准备、查询生成、SQL 执行、纠错、总结和绘图进度。可以查看耗时、执行 SQL、结果数据，或停止当前任务。
- **保存与复用分析**：手动保存有价值的结果，以卡片展示可交互图表、数据和 SQL。支持刷新数据，并通过“查看分析”返回原始对话。
- **按习惯设置工作台**：切换浅深色主题、选择发送快捷键和预览行数，并记住最近使用的分析方式。使用偏好自动保存在当前设备；设置中统一管理模型服务与已删除会话。

## 使用指南

### 下载与安装

安装包下载入口：**待补充**。后续发布后，可在此选择适合操作系统的安装包，下载安装后打开 Sive，无需配置 Node.js 或 pnpm。发布前可按下方开发指南从源码启动。

**后续补充视频**

会话草稿会在本机保存，关闭标签后可重新打开继续编辑；关闭标签不会停止后台分析。删除会话后可在「设置 → 已删除会话」中搜索、恢复或永久删除，分析结果和收藏会随会话一起恢复。删除数据源会永久删除其会话（包括已删除会话）、草稿和分析收藏，请先导出需要保留的结果。

## 开发指南

准备 Node.js >=22.13.0 和 [pnpm](https://pnpm.io/installation) 10.30.3，在项目目录执行：

```sh
pnpm install
pnpm run electron:install
pnpm dev
```

后续启动只需执行 `pnpm dev`。开发模式支持界面热更新；主进程或后端变化会重启应用，preload 变化会刷新窗口。

| 命令           | 用途                                    |
| -------------- | --------------------------------------- |
| `pnpm check`   | 类型检查                                |
| `pnpm build`   | 构建应用                                |
| `pnpm package` | 生成当前平台的应用包，输出至 `release/` |

界面代码位于 `src/`，业务逻辑位于 `backend/`，桌面入口位于 `electron/`，跨端公共代码位于 `shared/`。开发和构建配置统一在 `electron.vite.config.ts`。

页面使用 React Router 的 Hash 路由，兼容打包后的本地文件加载。路由表在 `src/router.tsx`，`App.tsx` 提供布局和共享工作区状态；欢迎页、数据源列表、新增数据源、分析详情、收藏和设置分别由路由渲染。数据源、会话和分析记录定位通过 URL 管理，标签与问题草稿由工作区保存。

数据预览、表结构和分析结果由 TanStack Query 管理读取状态与缓存，查询键包含数据或视图版本；写入与后台任务仍经由现有 IPC 和工作区订阅同步。Zod 定义共享输入规则，React Hook Form 通过 resolver 复用校验；持久化工作区使用独立的兼容性 schema。表格排序、分页和列宽由 TanStack Table 管理，分析页分栏使用 react-resizable-panels。

针对查询、输入校验、存储恢复和表格行为的回归检查（Node.js >=22.15）：

```sh
node --import ./tests/register-typescript.mjs --test tests/library-migrations.test.mjs
```
