<h1 align="center">🪼 Sive, See it Live, Share it Real.</h1>

An AI-powered data visualization creation platform by the AntV team. Build data visualization charts, reports, and perform data analysis through natural language conversations — making every insight instantly visible, accurate, and easy to share.

## Local file connections on desktop

CSV, JSON, XLSX and Parquet files are referenced by their original paths without copying. Rename a connection's display name or choose another source file to reconnect after a file is moved, renamed or deleted.

Opening a source data preview, starting an analysis or refreshing an insight Snippet checks for file changes and updates the schema and profile, without a background watcher. Refreshes reuse the original SQL: failures preserve the last successful result, while successful queries returning zero rows display an empty result. Original analysis records remain unchanged. Start a new analysis conversation after the source file changes.

Deleting a connection does not delete the source file or database. Historical analysis conversations and insight Snippets remain available to view and export, but cannot be continued or refreshed.
