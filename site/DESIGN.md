# Sive Desktop 官网

首屏以“数据理解 / 数据分析 / 数据可视化，交给 Sive”为轮播标题，使用系统苹方（PingFang SC），采用居中排版和紧凑字距，桌面端最大字号 68px。每项配一枚透明背景的立体 3D 图标：薄荷绿放大镜与数据表代表数据理解，杏橙色计算器代表数据分析，雾蓝色立体柱状图代表数据可视化。图标保留原有饱满的陶瓷与磨砂亚克力质感，补充柔和投影，与背景的 ASCII 暗纹及图片周围的数据流形成层次，文字与对应主色一起切换。图标和文字作为一组叠放在 CSS Grid 中，当前项向上移出，下一项从下方滚入，时长 600ms，间隔 3.2 秒。按最长词预留位置，轮播不推动后半句或下方内容；移动端“交给 Sive”另起一行。首屏去掉额外的产品标签与演示文字链接，下载按钮使用胶囊圆角。

首屏动效由 `hero.js` 负责：背景沿用最初预览的细密浅色 ASCII 暗纹，字符间距为 20 × 22px，不透明度小幅提高至最多 6%；主图周围保留三道字符流，提高圆环的基础亮度并稍微加密字符，使轮廓更清楚，颜色跟随标题切换。标题区域的暗纹再淡化至十分之一，背景不会遮挡文字或截图。鼠标靠近时局部字符轻微高亮；图片轻微倾斜并改变边缘柔光，点击图片或首屏空白触发一次扫光与环绕高亮。下载入口不触发扫描。主图下方不展示来源说明及动效控制按钮。暗纹缓存到独立画布，环绕层约每秒绘制 30 次，像素倍率上限为 2。原有布局和截图保持不变，图片加载、字体就绪或窗口变化后重新定位动效。动效和标题轮播在整段首屏离开视口或页面隐藏时停止；减少动态效果时保留静态暗纹并禁用扫描和倾斜。

首屏以一段话交代产品来源、定位与能力。四个特性版面分别用一个完整段落介绍多源连接、对话分析、分析溯源与图表生成，让新手看清用途、操作和结果。版面高度随图文内容自然展开，不强制占满一屏；桌面端每段上下留白各 72px，移动端各 52px，让四段之间更连贯。章节小标题左侧使用一套原创双色线性图标，分别表达数据汇流、对话展开、执行溯源和图表成形。

标题滚动进入视口后逐字出现，完整文本通过可访问名称提供给读屏软件。描述按自然词组错开上浮，形成轻柔的波浪，保留正常断行与完整文本，播放一次后停留；减少动态效果时直接呈现全部文字。

四个特性的演示图连同彩色底板在进入视口时，从下方 32px 处滑入并淡入，滑动持续 850ms、淡入持续 700ms，每张只播放一次。沿用文字的可见性观察器，减少动态效果时直接显示；JavaScript 未启用时图片仍然可见。

保留薄荷、浅橙、浅蓝与淡紫演示底板。首屏与四个特性按顺序使用 `assets/demo-overview.png` 和 `assets/demo-step-1.png` 至 `assets/demo-step-4.png` 五张本地截图，通过相对路径引用，图片按实际比例显示。

下载入口使用原生 details / summary，支持悬停、点击、键盘、Escape 与触屏。仅展示桌面端，Mac 和 Windows 提供芯片子菜单；未支持版本禁用并标记“待上线”。浏览器提供 CPU Client Hints 时标记芯片，否则只标记操作系统，不根据 MacIntel 字符串推断真实硬件。当前尚无 GitHub Release 资产，受支持版本链接先指向项目 Releases。

底部“开始分析你的数据”以薄荷绿、雾蓝色 ASCII 字符瀑布替代图标下落。36 列字符以不同速度持续向下流动，每列重复两段内容以无缝循环；上下边缘淡出，中央文字与按钮区域留白，手机上减少一半列数。`download.js` 生成装饰，CSS 负责动画；离开视口或页面隐藏时停止，减少动态效果时保留静态字符。装饰不响应指针且对读屏隐藏，标题、说明与下载按钮沿用单次淡入，键盘聚焦时立即显示内容。

页脚参考 AVA 官网的品牌简介、分组导航与底部信息栏，沿用 Sive 的浅灰背景和苹方字体。左侧将 AntV 与 Sive 标识并排展示，复用页头的分隔线与产品标识排版，下方介绍 Sive 的桌面工作台定位并标明由 AVA 驱动；导航分为产品、项目、社区与 AntV 生态，只提供现有功能锚点、下载、项目说明、开源协议及贡献反馈入口。桌面端品牌与四组导航并列，手机端品牌独占一行、导航两列排列。底栏保留团队版权与 Sive 标语，不展示字体链接。

页面无需构建，沿用现有 GitHub Pages / Surge 的 site 目录。正文优先使用系统苹方（PingFang SC），无苹方时回退到系统无衬线字体，不再加载 MiSans 网页字体。ASCII 动效继续使用等宽字体。

预览：在仓库根目录运行 `python3 -m http.server 4173 --bind 127.0.0.1 --directory site`
